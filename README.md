# Habitask 💜
> **Your Little Habbit Buddy** 

## ✨ Features

- **💜 Weekly Habit Tracker**:
  - Interactive day-by-day checklist (Mon–Sun) with automatic streak calculations.
  - Circular radial completion percentage meter for each habit.
  - Add, edit, and delete custom habits with custom emojis.
- **📝 Daily Task Planner**:
  - Filter tasks by day of the week, priority level (High, Medium, Low), or completion status.
  - Clean checkoff animations and counter badges.
- **🎯 Weekly Goals & Mini Calendar**:
  - Set weekly milestones and monitor weekly loads.
- **🎨 Customization & Profile**:
  - Custom profile emoji avatar picker.
  - Dark / Light mode toggle with smooth color transitions.
  - Editable quote callout and dashboard titles.
  - **Data Backup & Restore**: Export and Import full account data in JSON format from the profile dropdown.
